Sabotage in Battle - Player Guide

CODE BATTLE, 7 Oct 2026. In 1v1 and 3v3 matches a team can spend sabotages to disrupt the other team's screen or code.

Rules

  • Battle mode only. Competitions (Score / ICPC) have no sabotage.
  • Each team starts with 2 sabotages (default) and gets +1 for every question it solves (default).
  • Each use costs 1. At 0 you cannot use it until your team solves another question.
  • The count is shared by the whole team (3v3: teammates use the same pool).
  • The effect hits every player on the other team at the same time.
  • Cannot be used after the match ends.
  • The organizer can change the numbers or turn sabotage off. If it is off, the sabotage panel is hidden.

The five sabotages

NameWhat it doesDuration
BlurOpponent's screen is blurred. They can still type and click.10 sec
FlashbangScreen turns white, then fades back.10 sec
ShakePage shakes constantly.10 sec
Upside DownPage is rotated 180 degrees. Still usable.10 sec
DeleteRemoves one character from the other team's code.Permanent

About Delete

  • Position is random among characters that are not whitespace and not in a comment.
  • It hits the question that team edited most recently.
  • In 3v3 the code is shared, so every teammate sees the same change.
  • If the team has no code yet it misses, and the sabotage is still used up.
  • The affected players see a notice for about 5 seconds.
  • Counter: run the tests before every submit and re-read your code after a Delete notice.

One character disappears (shown for 3 seconds here; in a match it stays deleted).

How to use

  • Find the "Select Sabotage" panel next to the match screen. It shows how many you have left.
  • Press the button for the effect you want.
  • Your count drops by 1 and the other team is hit immediately.
  • The number of sabotages the opponent has left is shown under their name.

Tips

  • Sabotages do not expire during a match. Unused ones are lost when the match ends.
  • Delete is the strongest. Best used when the opponent is about to submit.
  • Visual effects work best while the opponent is reading a new problem.
  • In 3v3 agree in the team who presses the button, the pool is shared.
  • Visual effects do not stop you from submitting. If you are hit, wait 10 seconds or keep typing.

Describes the system as deployed (v1.3.12). The numbers above are the system defaults; the organizer may use different values at the event.
